# 产品范围

## 目标用户

在家庭局域网中通过 Android 手机或平板观看 NAS 视频，并需要稳定字幕、缩略图
和断点续播的用户。

## MVP 必须包含

1. 手动添加、测试、编辑和删除 SMB 服务器。
2. SMB2/3 共享与目录浏览；支持刷新、返回和名称排序。
3. 常见视频文件识别与播放，包含加载、失败、重试和断网提示。
4. 内嵌字幕选择；同目录外挂字幕自动匹配和手动选择。
5. 播放进度持久化和断点续播。
6. 视频列表异步缩略图、本地缓存和失败退避。
7. 播放页在播放前显示已解码视频帧，而不是黑屏。
8. 手机单栏与平板 list-detail 基础布局。
9. 凭证安全保存；日志和错误信息不得泄露凭证。

## 明确定义

### “视频预渲染”

- **列表封面**：后台从视频取帧并缓存为位图，列表中不创建播放器实例。
- **播放前首帧**：播放页提前 prepare，在暂停状态渲染首帧或续播位置附近帧。

二者验收和实现独立，不能用静态缩略图冒充播放器首帧已就绪。

### 字幕自动匹配

对于 `Movie.mkv`，可匹配 `Movie.srt`、`Movie.zh.srt`、`Movie.chs.ass` 等同前缀
文件。第一版只处理当前目录，不递归搜索。

## MVP 不做

- NAS 自动发现、DLNA、WebDAV、FTP、云同步
- TMDB 刮削、海报墙、媒体库全盘扫描
- 账号系统、弹幕、儿童锁
- 多播放器内核切换 UI
- 列表中视频自动播放

## 发布验收场景

至少在一台手机和一台平板/平板模拟器上验证：

1. 添加 SMB2/3 NAS，浏览包含 500 个条目的目录。
2. 播放 1080p H.264 和设备可硬解的 HEVC 文件，拖动到中后段。
3. 断网后收到可理解的错误，恢复网络后可重试。
4. 自动载入 UTF-8 SRT，并可选择内嵌字幕轨。
5. 退出后重进，在合理误差内恢复进度。
6. 首次进入目录逐步出现缩略图，再次进入命中缓存。
7. 打开播放页先出现视频帧，用户点击后开始播放。
