# 0025：模型完整性、字幕缓存与 SMB 安全默认

日期：2026-10-10。状态：已采用。任务：FN-63。

## 修复与兼容性

- SenseVoice 下载文件验证与 `.ready` 发布分开；验证成功后以同目录原子移动发布标记。权重与 tokens 均校验固定长度及 SHA-256。tokens 摘要来自固定 Hugging Face 修订 2365baeacb507f821a0c8120fcee3d484dba7a07 的原始 315894 字节文件：f449eb28dc567533d7fa59be34e2abca8784f771850c78a47fb731a31429a1dc。完整包在安装/首次 native 加载时验证，避免每个窗口重复读 239MB。
- Sherpa/Vosk 共用有界下载：写前检查剩余字节、严格核对完整 Content-Range、禁止 HTTP 降级/非提供方重定向、校验整个续传文件摘要，超长/损坏部分文件丢弃。正常中断保留有限部分文件以便重试。Vosk 解压有文件数、路径长度、累计展开大小上限及规范路径/重复路径检查。
- 显示选择始终优先有效文字；空白记录只说明窗口已处理，不能遮住同起点同 rev 的短句。数据库和内存平局排序确定化。
- 默认静音判断改为精确数字零。任意非零弱/短信号交给 ASR，完整 PCM/PTS 不变；默认缓存身份追加 digital-zero-v2，避免继续使用旧 RMS 静音结论。既有默认关闭的近数字静音实验仍独立。两者均不是语义 VAD，不能承诺过滤 BGM、识别质量或提速，更多片段进入 ASR 可能增加计算。
- 听译缓存生产入口接入最近 100 个 job、30 日未使用保留期限。活动会话以租约保护；清理和写入串行，明确清除会撤销租约，迟到写入不能重新创建已清除记录。活动数超限时保留活动会话，后续激活重新收敛。只处理本功能生成的缓存，不改变 NAS、凭证、播放历史。
- SMBJ 浏览和辅助读取默认要求签名与可用 SMB3 加密。协商后、认证后均失败关闭；不自动降级。服务器编辑提供明确的“仅要求签名、允许未加密”兼容选择，按服务器保存。Room 2→3 无损增加字段，已有服务器默认进入加密模式；不支持的 NAS 会给出编辑兼容选项的提示。此应用策略不改变 NAS/系统安全设置。
- libVLC 电影播放及 VLC 抓帧仍独立协商；SMBJ 的策略不能证明这些传输已加密。UI 明确写出此边界。

## 构建依赖校验

- GitHub Actions 固定至官方标签解析出的不可变 commit；Gradle 9.6.1 分发 SHA-256 来自官方 services.gradle.org 的校验文件。
- `gradle/verification-metadata.xml` 记录 GitHub Actions 实际解析的 623 个组件、1053 个产物的 SHA-256，包含元数据验证，没有 trusted-artifact 跳过例外。初始摘要在两次独立 Actions 构建产物中一致，随后提交并移除所有自动更新校验清单的 bootstrap 参数。后续 CI/发布必须使用严格校验，漂移时失败关闭。
- 这是对当前可信传输和现有依赖的初始摘要固定，不等同于每个原生库和依赖源代码的完整安全审查。没有升级业务依赖或改变已有签名 Secrets。
- Debug CI 不拥有发布私钥；Release 完整构建仍由既有显式请求工作流在证书固定值核验后执行，不绕过 requireReleaseSigning。
