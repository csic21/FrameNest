# 决策：桌面图标改为生成的双层画框

- 状态：accepted（母版是生成图；真机观感以这次安装后的桌面为准）
- 日期：2026-10-02
- 任务：用户要求把现有图标改得更简单

## 问题

0008 的符号是四块旋转影框、四个角标和中央播放键。小尺寸下形状叠在一起，看起来碎、重。

## 决定

1. 桌面图标使用生成的画面：午夜蓝底上两层圆角画框，中间一个暖白播放三角。不再使用旋转影框、角标，或一整块色面上的大三角。图标上没有文字。
2. 品牌源色、浅色/深色主题角色、`dynamicColor = false`，以及播放器上的功能色，仍按 0008 第 2 到第 5 点。
3. 整张生成图铺满自适应前景，背景用画面四角的午夜蓝。系统遮罩负责圆角。单色主题只保留画框和播放三角。
4. 母版是 `design/app-icon/framenest-logo-generated.png`。`generate_android_icons.py` 只把它缩放到各密度、自适应图层和单色主题，不再手写几何。旧的 `framenest-logo-approved.png` 只留作被替换的稿。

## 未选择的方案

- 继续用四块影框，只去掉角标：小图标上仍然是一圈碎片。
- 改成字母或带字的标志：48px 上字会糊，0008 已经排除文字。

## 后果

- 0008 第 1 点的旋转影框符号不再使用。第 6、7 点和「前景占画布 67.5%–69%」由本决定替换。
- 单色主题图标保留画框和播放三角，由系统着色。
