# 决策：映舟显示名称与安装身份分离

- 状态：accepted
- 日期：2026-10-14
- 任务：FN-71

## 问题与证据

用户接受「映舟」作为播放器名称，并确认统一应用内显示名称，同时保留安装与数据兼容性。

## 决定

将应用及启动器 label、调试入口 label、更新提示和诊断分享可见名称改为「映舟」。
`app_name` 为不可翻译的中文品牌名称，英文系统也使用「映舟」。

保留 FrameNest 技术标识：`com.framenest`、类名、资源标识、主题、日志 tag、
诊断文件名、签名、数据库及数据路径、仓库、更新地址与发布资产命名均不变。

## 未选择的方案

不更换 applicationId 或数据路径，否则会破坏覆盖安装与现有数据兼容性。
不为英文系统创造新的英文产品名，也不重写历史发布记录。

## 验证与后果

新增 Android 仪器测试，覆盖应用/启动器标签、包名以及手机/平板配置下中英文资源解析。
本环境缺少可用 Android 构建工具链，Gradle wrapper 下载被网络阻断；测试尚未编译或在设备运行。
静态 XML、manifest label、包名与更新端点检查通过。后续仍需构建及手机/平板启动验证。
