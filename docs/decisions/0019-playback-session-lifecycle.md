# 决策：播放意图、会话退出与临时资源的边界

- 状态：accepted（代码与自动回归；设备/NAS 验收范围见 FN-54 交接）
- 日期：2026-10-08
- 任务：FN-54

## 问题与证据

- direct SMB 的续播位置保存在 controller 的 pendingSmbResumePositionMs，Ready 的 native
  时钟仍在首帧附近。旧 VM 把这个时钟存回历史，仅打开再返回就能覆盖已有续播点。
- ON_STOP 调 pause，ON_START 只重新挂接画面，没有保存先前的播放意图。等待延迟音频
  焦点时也没有撤销请求，后台可能收到 GAIN 并开始播放。
- 显式 Back 只释放 VLC，字幕、听译、预览等工作要等 ViewModel 真正清除才结束。
  旧会话还会清空全局字幕目录，影响紧接着打开的新会话。
- 预览内存只留 36 桶，scheduler 的 ready 集合却不会随淘汰失效。
- ML Kit 翻译 client 在模型下载之后才登记；下载取消时 close 无法回收未登记 client。

## 决定

1. 播放意图属于当前 destination，独立于 native Playing/Paused 事件。首次进入继续
   prepare 后暂停。后台保留用户播放意图并暂停、撤销焦点；回来等视频表面真正可用，
   再申请本次焦点。原来手动暂停或首次预览继续暂停。旧表面或旧焦点回调不能启动播放。
2. 旋转/窗口表面重建不是退出。控制锁、方向锁与全屏意图使用可恢复 UI 状态；换视频
   重新初始化。导航退出立即取消会话 scope、使字幕/听译代次失效、清空临时 UI、
   撤销焦点并启动一次释放。onCleared 只是幂等回退，不再起第二次保存/释放线程。
3. 保存使用 controller.progressState：未消费的 SMB 续播点、尚未完成的定位点优先于
   首帧附近的 native 时钟。主动定位零秒是有效进度，重试也必须保留零秒。历史、
   服务器和用户设置不删除。
4. 周期、后台、退出历史快照统一串行写；退出不取消尚未完成的数据库写。
   强制退出快照总是先入队，在串行写内按已成功保存的快照去重；失败可由下一次快照重试。打开同一
   文件的 route/VM 读取历史前等待已排队写入，避免快速重开读到旧进度。
   本项取代决策 0006 第 6 点的取消 leave-save + teardown 备用写方案。
5. 每个播放会话使用独立字幕临时目录，取消后的旧结果不得发布或重建已关闭目录。
   原有未指定会话 key 的 loader 保留默认缓存行为。听译准备只有在回到主线程并检查
   当前代次后才能转移资源所有权；ML Kit client 从创建时即归当前 engine 管理。
6. 预览淘汰同步使 ready 失效；每轮预热有界，避免淘汰/重载死循环。关闭和取消后的
   late frame 不发布，丢弃的独占 Bitmap 与部分创建的 native 资源均释放。

## 保持不变

- 决策 0007 的 direct SMB、硬件播放解码、凭证通过 options、无运行时路径 fallback。
- 决策 0011 的有界 seek/重播、0012/0017 的独立拖动预览与松手定位。
- 决策 0017 的前台表面重新挂接；本决策补充恢复先前播放意图，而非要求再手点播放。
- 模型选择、下载策略、翻译内容、历史完成判定和持久用户设置。

## 验证边界

测试覆盖生产生命周期协调器、真实 scheduler、保存串行顺序、独立字幕目录与翻译
client 所有权；另有实际产品 PlayerScreen/ViewModel/navigation 的本地样本测试，及
控制 native 事件顺序的 VM/VLC/Room 回归。AndroidTest 编译不等于设备运行；受控
事件不等于真实出帧或 NAS 性能。手机/平板/真实 NAS 的执行结果单列在交接记录。

## 本轮审阅修正

- 字幕手动选择只使自动选轨失效，不能丢弃同一次目录结果中的兄弟视频、字幕选项与
  loading/scanning 完成状态。离开会话的取消/closed 守卫仍然有效。
- 不在第一次 native play 之前读取音量并尝试以返回码证明静音。已核对本次 libVLC
  OpenSLES 的初始化路径：音量接口到 Start 才可用，pre-start 设置可被丢弃，初始 getter
  也不能用来推断用户播放音量。本轮撤回新增的首帧/Preparing 静音与恢复逻辑，保留
  原有开始播放后的 seek-preview 行为。此处是回到既有音频行为，不代表已证明准备阶段
  无音频；真实带音轨样本仍需设备验收。
