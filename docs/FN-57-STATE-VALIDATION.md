# FN-57 播放状态验收矩阵

本轮重点是会话边界与恢复。离开视频清理的是当前会话、临时界面状态、回调和资源；历史进度、服务器配置和用户设置需要保留。

| 场景 | 必须保持的行为 | 自动化 / 设备验证 |
|---|---|---|
| 历史已有进度，打开后未播放直接返回 | 不用首帧附近的零秒覆盖历史 | 待集成核验 |
| 用户明确定位到零秒后退出 | 能保存用户主动选择的零秒，不用“只增不减”掩盖错误 | 待集成核验 |
| 正在播放时进入后台再回来 | 同一视频和进度；表面可用且焦点允许后恢复原播放意图 | 待集成核验 |
| 手动暂停后进入后台再回来 | 保持暂停，画面和操作仍可用 | 待集成核验 |
| 等待音频焦点时进入后台，随后获得焦点 | 不在后台意外启动；过期请求不能影响新会话 | 待集成核验 |
| 退出 A 后立即打开 B | A 的首帧、seek、字幕、听译和预览回调不能更新 B | 待集成核验 |
| 快速返回、重复退出、再次进入同一视频 | 清理幂等；旧会话不能删除新字幕缓存或覆盖更新的历史 | 待集成核验 |
| 旋转、窗口变化、锁屏再解锁 | 不把表面重建误当作导航退出；保留正确播放意图并重新挂接画面 | 待集成核验 |
| 加载失败或断网后退出、再进与重试 | 不残留旧错误、旧加载状态或后台工作 | 待集成核验 |
| 拖动超过 36 个预览位置再返回被淘汰位置 | 能重新加载正确预览；旧帧完成不能写回已退出会话 | 待集成核验 |
| NAS 无响应时刷新/返回、随后发起新请求 | 主线程及时返回；旧连接清理不影响新请求 | 待集成核验 |
| 播放页退出后的系统状态 | 释放临时全屏、屏幕常亮、音频焦点与会话资源，保留用户持久设置 | 待集成核验 |

每项记录实际执行的测试与结果。单元测试、AndroidTest 编译、模拟器运行与真实 NAS/设备实测是不同覆盖层，不能互相代替。
