# 真实 NAS 验收清单（用户侧）

工程侧自动化与模拟器路径已通过。请在家庭局域网中勾选下列项并记录设备。

## 准备

1. 安装 `0.3.1-internal` debug APK（或对应 ABI 分包）。
2. 手机 + 平板（或模拟器）各一台。
3. SMB2/3 NAS；建议准备：
   - 含 **≥500** 条目的目录
   - **1080p H.264** 与（可选）**HEVC** 样本
   - 同目录 **UTF-8 `.srt`** 与可选 **内嵌字幕 MKV**

可选：根目录 `smb.local.properties`（**勿提交**）预填 debug spike：

```properties
smb.host=192.168.x.x
smb.port=445
smb.username=...
smb.password=...
smb.share=media
smb.path=/
```
