### 匹配算法摘要

1. **候选过滤**：字幕扩展名 ∈ {srt,ass,ssa,vtt}；stem 等于视频 basename，或以 `basename.` 为前缀（大小写不敏感）。`MovieExtra.srt` 不匹配 `Movie.mkv`。
2. **语言分**：从 stem 去掉 basename 后的 `.` 分段为 tags（如 `Movie.zh-CN.forced.srt` → `[zh-CN, forced]`）。对 `SubtitleLanguagePrefs.preferredLanguages(Locale)` 逐项计分（精确 > 同基语言 > 别名 chs/chi/eng 等）；无 tag 的 `Movie.srt` 略低于首选语言、高于次选语言。
3. **格式分**：ass(40) > ssa(30) > srt(20) > vtt(10)。
4. **排序键**：languageScore ↓，formatScore ↓，tag 数量 ↑，文件名 CI ↑。
5. **自动应用**：首帧就绪后扫描；有外挂则加载排序第一项；否则按轨名语言分选内嵌；都无则关闭。

### 外挂字幕如何送给 libVLC

**不**使用带凭证的 `smb://` 字幕 URL。

```text
SmbjClient.connect(credentials)          // 与浏览相同，密码不进 URL
  → listDirectory(share, parentPath)     // 仅当前目录
  → openRandomAccess(share, remotePath)  // 读字幕字节
  → SubtitleEncoding.decode → UTF-8 文本
  → 写入 app cacheDir/subtitles/<hash>-name
  → MediaPlayer.addSlave(Slave.Type.Subtitle, file://localPath, select=true)
  → refreshTracks / setSpuTrack
```

路径 B 视频仍走 seekable FD；字幕是独立的本地 slave。ViewModel `onCleared` 时清理字幕缓存。
