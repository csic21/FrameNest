- 验收结果：
  - 真机复现（OnePlus PME110 / Android 17，0.6.3-internal versionCode 14，SenseVoice 已安装）：
    开启听译后进程立刻消失；`ApplicationExitInfo reason=1 (EXIT_SELF) status=255`；
    logcat `F sherpa-onnx: Read binary file: Load '.../tokens.txt' failed`，native 栈
    `Java_com_k2fsa_sherpa_onnx_OfflineRecognizer_newFromAsset → exit+40`，Zygote `exited cleanly (255)`；
    崩溃缓冲区无 Java FATAL。原因是 `0e76bca` 起把进程 `AssetManager` 传入绝对路径模型加载。
  - 修复构建覆盖安装（同一证书 `31324de5…` 签名、保留数据）后实测：开启听译不再退出，
    依次显示「正在载入本机 ASR 模型 → 正在准备本机翻译模型」，模型就绪、识别与译文 cue
    正常写入并显示（双语叠加实测可见）；连续播放期间进程存活，exit-info 无新增 `EXIT_SELF`。
