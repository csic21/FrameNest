### Room schema（version 1）

```text
table servers:
  id TEXT PK
  name TEXT
  host TEXT
  port INT
  username TEXT
  domain TEXT NULL
  credentialAlias TEXT   -- NOT password
  defaultShare TEXT NULL
  createdAtMs LONG
  updatedAtMs LONG
```

密码：`EncryptedCredentialStore` prefs `fn_server_credentials`，key = credentialAlias。

### 导航路由（FN-05 必须对齐）

```text
Browse:
  servers/browse/{serverId}?share={share}&path={path}
  - share 空：共享列表
  - share 有、path 空：共享根目录
  - 均有：共享内相对路径目录

Player（占位 → FN-05 正式实现）:
  player/{serverId}?share={share}&path={path}
  - share: SMB 共享名
  - path: share-relative，无前导 /（SmbPathUtils.normalizeRelative）
  - 构建：FrameNestRoutes.player(serverId, share, path)
  - 禁止密码进路由 / URL / 日志
```
